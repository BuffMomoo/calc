# Calculator Website
A simple calculator website built with HTML, CSS, and JavaScript.

## Features
Add, subtract, multiply, and divide numbers
Use percentage calculations
Clear the calculator with AC
Delete the last character with DEL
Use the calculator with mouse clicks or keyboard input
Works directly in the browser

## Project Files
index.html - Main calculator page
styles.css - Calculator design and layout
script.js - Calculator logic and keyboard support
server.mjs - Optional local preview server
